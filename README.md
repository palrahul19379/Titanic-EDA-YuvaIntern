# Titanic EDA and Visualization – YuvaIntern Week 2

## 📌 Project Overview

This project was completed as part of the YuvaIntern Week 2 task on Exploratory Data Analysis (EDA) and Visualization.

The project focuses on analyzing the Titanic dataset using Python and popular data analysis and visualization libraries.

## 🎯 Objectives

- Understand the structure of the Titanic dataset
- Perform initial data exploration
- Generate statistical summaries
- Identify missing values
- Analyze duplicate records
- Handle missing values
- Analyze numerical and categorical variables
- Study correlations between variables
- Detect potential outliers
- Create meaningful visualizations
- Extract important insights from the dataset

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Dataset

The project uses the Titanic dataset available through the Seaborn library.

The dataset contains information about passengers, including variables such as:

- Passenger class
- Sex
- Age
- Fare
- Port of embarkation
- Survival status
- Other passenger-related attributes

## 🔍 Analysis Performed

The notebook includes:

1. Dataset loading
2. Initial data exploration
3. Dataset shape and column analysis
4. Dataset information and data types
5. Statistical summary
6. Missing value analysis
7. Duplicate value analysis
8. Missing value handling
9. Data cleaning
10. Categorical and numerical analysis
11. Correlation analysis
12. Data visualization
13. Outlier analysis
14. Key findings and conclusions

## 📈 Visualizations

Multiple visualizations were created using Matplotlib and Seaborn to understand patterns and relationships in the dataset.

These include comparisons based on passenger survival, gender, class, age, fare, and port of embarkation.

## 📁 Project Files

- `missing_value.ipynb` – Main Jupyter Notebook containing the complete analysis, Python code, explanations, and outputs.
- `Titanic_EDA_YuvaIntern_Week2_Final_Report.docx` – Detailed project report.

## 💡 Key Learning

This project helped in understanding the complete basic EDA workflow, including data inspection, statistical analysis, missing-value handling, visualization, and interpretation of results.
